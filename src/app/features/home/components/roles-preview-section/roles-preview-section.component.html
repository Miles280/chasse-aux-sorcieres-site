Choisissez votre destin

À Nistrium, personne n'est innocent. Découvrez les forces qui s'affrontent dans l'ombre.

Les Défenseurs du Village

Majoritaires mais ignorants, leur force réside dans le nombre et la déduction. Leur objectif est simple : éradiquer le mal avant qu'il ne soit trop tard. Parmi eux se cachent des rôles puissants : la Voyante, le Chevalier, ou encore le Chasseur.

Le Coven des Sorcières

Elles connaissent leurs alliés et frappent chaque nuit. Manipulatrices expertes, elles doivent se fondre dans la masse le jour pour mieux égorger la nuit. Leur victoire est totale si le village est réduit à néant.

Les Indépendants

Ni gentils, ni méchants... ils jouent pour eux-mêmes. Leurs objectifs sont uniques : survivre seul, assassiner une cible précise, ou semer le chaos total. Ce sont les électrons libres qui font basculer les parties.
